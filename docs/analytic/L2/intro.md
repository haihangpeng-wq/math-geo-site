# 解析几何的方法论

**方法论**是在世界观的基础上，讨论「怎么算」——即如何用解析几何高效地完成竞赛题的计算过程。

> 锅还是这个锅，铲子还是这个铲子，但做出的菜味道不一样。说明这里面有方法论可言。

---

## 四大被动技

本讲总结《9+2》中四个已被提炼的核心技巧，见到就要会用：

| 技巧 | 核心思想 |
|------|----------|
| [§1 简洁是宗教](./simplicity) | 意志是勇气，节约注意力；拒绝一切人造括号、人造分式与无谓展开 |
| [§2 分阶段移轴](./shift-axis) | 远离常数项，不吃眼前亏；不同阶段移到当前核心点 |
| [§3 溢出设变量](./overflow-variables) | 超出代数直觉的量立即设出来；多个约束多条路 |
| [§4 免解坐标流](./coordinate-flow) | 隐约束和显式表达式看起来一样，吃起来也一样 |

## 方法论的定位

**世界观**解决的是「翻译条件」的问题：你有几招生成圆，有几种刻画直线交点的方法。

**方法论**解决的是「走哪条路」的问题：同样的工具，决定最终计算量的是选择。

> 很多人说计算几何就是翻译条件无脑计算。这样说的人，人均不会点到直线垂足公式。
