§4 免解坐标流

隐约束和显式表达式，看起来一样，吃起来也一样。

核心思想：不需要解出显式坐标，直接把「点满足的约束」设为中间变量，验证约束之间的冗余关系即可。这是溢出设变量的一种特殊形式，专门用于回避困难的交点。

§4.0 什么是坐标流？​

坐标流是一种中间变量，直接设出横/纵坐标（或两者），占用 1–2 个自由度。

:::note 核心观点 破除对变量显式表达式的依赖。

  • 显式坐标 x=X(b,c)x = X(b,c)x=X(b,c)，y=Y(b,c)y = Y(b,c)y=Y(b,c)：理论上可以万能代入，但如果 X/YX/YX/Y 形式复杂或带根号，考场上几乎不可用；
  • 更多时候，用 P(x1,y1)=f1∩f2P(x_1, y_1) = f_1 \cap f_2P(x1​,y1​)=f1​∩f2​ 来描述（两个方程的交点）；
  • 可以确知，在需要化简的式子里，(x1,y1)(x_1, y_1)(x1​,y1​) 必然只以 f1f_1f1​ 和 f2f_2f2​ 中的形式出现（原理见 §4.1.4）；
  • 只要在要验证的结论里，将 f1f_1f1​ 和 f2f_2f2​ 凑出即可：设而不求，必然成功。 :::

§4.1 具体操作：两圆相交的未知交点​

设定​

圆1: x2+y2=d1x+e1y+f1x^2+y^2 = d_1x + e_1y + f_1x2+y2=d1​x+e1​y+f1​
圆2: x2+y2=d2x+e2y+f2x^2+y^2 = d_2x + e_2y + f_2x2+y2=d2​x+e2​y+f2​
根轴: ax+by+f=0ax + by + f = 0ax+by+f=0（令 (d2−d1)=a(d_2-d_1) = a(d2​−d1​)=a，(e2−e1)=b(e_2-e_1) = b(e2​−e1​)=b，f2−f1=ff_2 - f_1 = ff2​−f1​=f）

设 P/Q=(xi,yi)P/Q = (x_i, y_i)P/Q=(xi​,yi​)，i=1/2i = 1/2i=1/2，则 (xi,yi)(x_i, y_i)(xi​,yi​) 服从三约束：圆1、圆2、根轴。

§4.1.4 为什么三约束一定够用？​

代数理由（扩域）：

  • 有理函数域 R(x)\mathbb{R}(x)R(x) 添加 Q\sqrt{Q}Q​ 得到的扩域对加减乘除封闭；
  • x1,y1x_1, y_1x1​,y1​ 解出来，均为 Pi+QiRP_i + Q_i\sqrt{R}Pi​+Qi​R​（same RRR）的形式；
  • ax1+by1+f=0ax_1 + by_1 + f = 0ax1​+by1​+f=0 说明 aQ1+bQ2=0aQ_1 + bQ_2 = 0aQ1​+bQ2​=0，即：不存在其他线性组合使 cx1+dy1∈Qcx_1 + dy_1 \in \mathbb{Q}cx1​+dy1​∈Q（c/d≠a/bc/d \neq a/bc/d=a/b）；
  • 不仅 cx1+dy1cx_1 + dy_1cx1​+dy1​ 不行，(cx1+dy1)2(cx_1 + dy_1)^2(cx1​+dy1​)2 也不行；
  • 由于结论是有理的，则结论化简中「需要」的形式一定是三约束中三个「头」之一。
坐标流不是奇技淫巧，而是可靠操作，结果可预期。\boxed{\text{坐标流不是奇技淫巧，而是可靠操作，结果可预期。}}坐标流不是奇技淫巧，而是可靠操作，结果可预期。​

§4.3 两个金标准​

§4.3.1 约束带变量部分最多四项​

约束超过四项，在化简中凑不出来。

例（A(0,0)A(0,0)A(0,0) 框架下）：

  • 外接圆 OOO: f=x2+y2−(−b+c)x+(1+bc)y=0f = x^2 + y^2 - (-b+c)x + (1+bc)y = 0f=x2+y2−(−b+c)x+(1+bc)y=0（四项，是可用极限）
  • 设外接圆上一点 P(x1,y1)P(x_1, y_1)P(x1​,y1​)，满足 f=0f = 0f=0，这是可接受的约束复杂度
警告

比这再复杂，就用不了了。如果约束形式过于复杂，先移轴使约束简化，再设坐标。

§4.3.2 变量名要鲜明​

标准：见变量名即可立即 recall 是哪个点的坐标，节约注意力。

形式尽量设成整式，有分母照例设出来：

  • T(2t,2s)T(2t, 2s)T(2t,2s)（消掉分母2）
  • X(x1,y1)X(x_1, y_1)X(x1​,y1​)（鲜明指向点 XXX）
  • O(m,n)O(m, n)O(m,n)
  • A(abn−1,b2n−1)A(abn^{-1}, b^2n^{-1})A(abn−1,b2n−1)（有分母则整体设出）

§4.4 一个交点对，一个不对​

:::info 背景 这是 jv（数之谜 @johnvector）提出的问题。 :::

设定：结论点 P(x1,y1)P(x_1, y_1)P(x1​,y1​) 满足约束 f=0f = 0f=0，要证的结论是 g=0g = 0g=0，其中 fff 和 ggg 都是关于某主元 xxx 的首一多项式，且至少有一个（经常两个）形式复杂，无法直接解出根。

绝大多数赛题可以描述成：「PPP 如图是唯一的，它是 fff 的一个根，求证也是 ggg 的一个根。」

情形一：fff 和 ggg 等价​

最常见。此时 fff 的全部根都满足 ggg。

处理方法：赋值不展开，验证 f≡gf \equiv gf≡g（对应项系数成比例）。「如图」说明 PPP 是唯一的，即证。

情形二：fff 和 ggg 不等价，但手性对称结论成立​

两个约束不等价，是因为结论只取了一半（有手性）。实际上，结论的手性对称版本（另一侧）也成立。

处理方法：加强命题至两个结论（去手性），多用曲线系，应当可以快速得到结果。

情形三：fff 和 ggg 不等价，但都是二次的，PPP 是唯一公共根​

fff 有两个根 P,QP, QP,Q：PPP 满足 ggg，QQQ 不满足。

处理方法：

h=f−g⇒h 必然等于 K(x−x1)=0h = f - g \Rightarrow h \text{ 必然等于 } K(x - x_1) = 0h=f−g⇒h 必然等于 K(x−x1​)=0

从而可以降次瞪出根 x1x_1x1​，然后先宣称再验证。

情形四：fff 和 ggg 不等价，次数不同，PPP 是唯一公共根​

处理方法（类辗转相除）：

h3=g−x2f=0（三次）h_3 = g - x^2 f = 0 \quad \text{（三次）}h3​=g−x2f=0（三次） h2=h3−xf=0（二次）h_2 = h_3 - x f = 0 \quad \text{（二次）}h2​=h3​−xf=0（二次） h1=h2−f=0（一次，即 x−x1=0）h_1 = h_2 - f = 0 \quad \text{（一次，即 } x - x_1 = 0\text{）}h1​=h2​−f=0（一次，即 x−x1​=0）

实战中不需要化到 h1h_1h1​，只要 hih_ihi​ 足够简单可以因式分解瞪出 x1x_1x1​ 即可，然后先宣称再验证。

:::tip 关键洞察 题目的难度是有限的。只要结果是简单的（有理的），就一定有不可忽略比例的人能观察/猜出来。要勇敢地猜点。 :::

例题​

巨佬杯 P2​

题意：圆 ω\omegaω 内接四边形 ABCDABCDABCD，ACACAC 与 BDBDBD 交于 EEE，FFF 在线段 ACACAC 上满足 AE=CFAE = CFAE=CF。过 FFF 作 CDCDCD 的平行线与 ABABAB 交于 III，III 关于 AFAFAF 中垂线的对称点为 JJJ，过 JJJ 作 ω\omegaω 的切线切于 PPP，延长 PFPFPF 与 ω\omegaω 交于 KKK，△FPJ\triangle FPJ△FPJ 的外接圆与 ω\omegaω 交于 MMM，求证：K,M,JK, M, JK,M,J 三点共线。

这是用解析做，几乎唯一的解法。

关键步骤（Proof by RynW1988）：

P(0,0),  B(−b,−1),  C(c,−1),  2m=−b+c,  −2n=1+bcP(0,0),\; B(-b,-1),\; C(c,-1),\; 2m = -b+c,\; -2n = 1+bcP(0,0),B(−b,−1),C(c,−1),2m=−b+c,−2n=1+bc ⊙PBC:  x2+y2=2mx+2ny\odot PBC:\; x^2+y^2 = 2mx + 2ny⊙PBC:x2+y2=2mx+2ny KPJ=−m/n,PJ:  ny+mx=0K_{PJ} = -m/n,\quad PJ:\; ny + mx = 0KPJ​=−m/n,PJ:ny+mx=0

设 J(nj,−mj)J(nj, -mj)J(nj,−mj)，从 F(f,−1)F(f,-1)F(f,−1) 翻转得 JJJ 坐标（不展开 jjj），再推出 III，用曲线系写出 ⊙ABCD\odot ABCD⊙ABCD。

核心技巧：图形生成顺序——先设 JJJ 的坐标，躲避「两条复杂直线相交」的困难交点，然后用曲线系写大圆方程。

:::note 通用技巧 要验证 EFEFEF 和 ACACAC 共中点，等价于这两条直线相乘生成的曲线系被横轴截，中点是 ACACAC 的中点。方程麻烦也无所谓，因为最终验证时 y=0y = 0y=0。 :::
