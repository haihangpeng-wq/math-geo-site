§2 分阶段移轴

移轴现在已经不是个技巧，是个习惯。

核心思想：不同阶段，生成图形的「核心点」不同。每到一个新阶段，就把核心点移到原点，远离常数项。

§2.0 移轴是内禀的被动技​

移轴不是「技巧性便利」，而是解析的本质操作，原因如下：

  1. 生成图形的点重要性不同：不同阶段的核心点不同；
  2. 平几结论是平移不变量：距离、方向、共点/共线/共圆等结论在平移下保持；
  3. 代数上，无常数项的多项式显著简洁，并且有齐次化技巧（将 f(x,y)=0f(x,y)=0f(x,y)=0 化成 f(t)=0f(t)=0f(t)=0，t=y/xt = y/xt=y/x）；
  4. 因此，你需要「分阶段移轴」，确保当前核心点始终是原点（大杀器）。

§2.1 移轴的操作好处与注意事项​

好处​

  • 打得一拳开，免得百拳来：只需移一次 Part2 相关坐标，比全程带着复杂常数项强得多；
  • 对称算一半：移轴到结论的对称中心后，结论从不对称恒等式变成两边对称的恒等式，只算一边，节约 50% 计算量和错误率。

:::tip 例子 验证 KPE=KQEK_{PE} = K_{QE}KPE​=KQE​（某题），不移轴需验证繁琐非对称恒等式要算两边；
移轴到 EEE 后，KPE=f(a,b,c,d)K_{PE} = f(a,b,c,d)KPE​=f(a,b,c,d) 必然对 a/ca/ca/c（b/db/db/d）对称，只算一边即可。 :::

注意事项​

  1. Part2 相关的才动，大多数不用动；
  2. Part2 参与运算的都要动，一定检查有没有少移一个；
  3. Part2 和 Part1 交互时，记得把坐标/方程移回来。

§2.2 原点版补充公式​

没有足够多的零，复杂公式根本没法用，所以默认要移轴。以下公式建议记住原点版：

任意点版：h=Ax0+By0+CA2+B2,原点版（x0=y0=0）：h=CA2+B2\text{任意点版：} h = \frac{Ax_0 + By_0 + C}{\sqrt{A^2 + B^2}}, \quad \text{原点版（}x_0=y_0=0\text{）：} h = \frac{C}{\sqrt{A^2+B^2}}任意点版：h=A2+B2​Ax0​+By0​+C​,原点版（x0​=y0​=0）：h=A2+B2​C​

以上公式，移轴后的版本才能在考场上实战使用。

高考的特别提示​

:::info 几乎 100% 的高考解析压轴题，移轴都可以简化运算 原因推测：高考压轴题有固定的运算量要求，但代数内涵不能太难，所以总让生成图形的点带常数项。移轴一次，常数项消失，运算量立即减半。

如果你所在的地方允许移轴：几乎每道高考压轴题都可以用移轴简化。 :::

例：高考抛物线正三角形​

题意：抛物线 y2=2pxy^2 = 2pxy2=2px 上点 AAA，l1l_1l1​ 过 AAA 斜率为 k1k_1k1​ 与抛物线只有一个公共点，l2l_2l2​ 过 AAA 斜率为 k2k_2k2​ 与抛物线交 B,CB, CB,C。若 △ABC\triangle ABC△ABC 是正三角形，求 k1/k2k_1/k_2k1​/k2​ 的范围。

移轴至 A(0,0)A(0,0)A(0,0) 后，设 AB,ACAB, ACAB,AC 过原点斜率为 t,st, st,s，利用正三角形条件得到旋转关系：

t=u+31−3u,s=u−31+3ut = \frac{u + \sqrt{3}}{1 - \sqrt{3}u}, \quad s = \frac{u - \sqrt{3}}{1 + \sqrt{3}u}t=1−3​uu+3​​,s=1+3​uu−3​​

其中 u=k2u = k_2u=k2​，最终化简得 f=v/u∈(−1,1/7)∖{0}f = v/u \in (-1, 1/7) \setminus \{0\}f=v/u∈(−1,1/7)∖{0}。

例：椭圆内心问题​

题意：椭圆 x2/2+y2=1x^2/2 + y^2 = 1x2/2+y2=1，右焦点 FFF，上顶点 MMM。是否存在直线 lll 交椭圆于 P,QP, QP,Q，使 FFF 是 △MPQ\triangle MPQ△MPQ 的内心？

移轴至 M(0,0)M(0,0)M(0,0) 后，原点 O(0,−1)O(0,-1)O(0,−1)，F(1,−1)F(1,-1)F(1,−1)，椭圆方程更新。利用内心条件（∠PMF\angle PMF∠PMF），通过角分线公式和内心到各边等距，解出直线方程。

例题：IMO 2025 P2​

建系：A(0,0),B(−b,−1),C(c,−1)A(0,0), B(-b,-1), C(c,-1)A(0,0),B(−b,−1),C(c,−1)（利用 BCBCBC 的对称中心）

计算步骤：

  1. M,NM, NM,N 的坐标（AB,ACAB, ACAB,AC 的垂直平分线与 BCBCBC 的交点）
  2. △PMN\triangle PMN△PMN 的垂心 HHH（有理）
  3. E,FE, FE,F 的坐标（圆斜式，有理）
  4. 移轴至 L(0,−2)L(0,-2)L(0,−2)（圆 LEFLEFLEF 悬浮，唯一已知点是 LLL）
  5. 验证圆心到切线的距离等于半径
