§1 简洁是宗教

如果你们非得叫我教主，就叫我简洁教教主。

核心思想：一道题内含的代数难度是不变的。只要计算路径不是特别非常规，从哪条路走都有必须攻克的计算难关。尽量把体力和注意力留给那个地方，之前的路上能省就省。

§1.1 拒绝人造括号和人造分式​

§1.1.1 不使用点斜式 / 圆的标准方程​

直接用直线的头和圆的头展开写整式，不要人造括号。

直线的头：已知斜率 k=A/Bk = A/Bk=A/B，则直线方程写作

By−Ax=好算的点(x0,y0) 代入后的值By - Ax = \text{好算的点} (x_0, y_0) \text{ 代入后的值}By−Ax=好算的点(x0​,y0​) 代入后的值

圆的头：已知圆心 (d,e)(d, e)(d,e)，则圆方程写作

x2+y2−2dx−2ey=好算的点代入后的值x^2 + y^2 - 2dx - 2ey = \text{好算的点代入后的值}x2+y2−2dx−2ey=好算的点代入后的值

这样，点 (x,y)(x, y)(x,y) 对直线（或圆）的幂就是直接代入左端的值，语义清晰，好习惯减少错误。

§1.1.2 不使用分式版直线方程​

两点式、垂直平分线、两直线垂直，直接写整式版：

两点式：(x−x1)(y2−y1)−(y−y1)(x2−x1)=0\text{两点式：} (x - x_1)(y_2 - y_1) - (y - y_1)(x_2 - x_1) = 0两点式：(x−x1​)(y2​−y1​)−(y−y1​)(x2​−x1​)=0 垂直平分线：2(y2−y1)y+2(x2−x1)x=y22−y12+x22−x12\text{垂直平分线：} 2(y_2 - y_1)y + 2(x_2 - x_1)x = y_2^2 - y_1^2 + x_2^2 - x_1^2垂直平分线：2(y2​−y1​)y+2(x2​−x1​)x=y22​−y12​+x22​−x12​ 两直线垂直：(y2−y1)(y3−y1)+(x2−x1)(x3−x1)=0\text{两直线垂直：} (y_2 - y_1)(y_3 - y_1) + (x_2 - x_1)(x_3 - x_1) = 0两直线垂直：(y2​−y1​)(y3​−y1​)+(x2​−x1​)(x3​−x1​)=0

:::tip 口诀 已知斜率是 A÷BA \div BA÷B 时，直线的头一定是 Bx−AyBx - AyBx−Ay，后面带一个已知点代入得到常数。 :::

§1.1.3 不展开，目押系数​

对于关于 ttt 的多项式 f(t)=g1(t)+g2(t)+⋯f(t) = g_1(t) + g_2(t) + \cdotsf(t)=g1​(t)+g2​(t)+⋯，如果各项结构已知，直接用眼睛看出每个系数，不要抄写展开再合并同类项。

你抄他的唯一功能就是抄错。

适用场景：当 f(t)f(t)f(t) 是关于 ttt 的二次多项式，各 gig_igi​ 复杂但结构已知时，直接目押 A0,A1,A2A_0, A_1, A_2A0​,A1​,A2​。

§1.1.4 赋值不展开​

核心想法：如果要验证某个变量 t1=t2t_1 = t_2t1​=t2​，不需要解出显式表达式，只需验证两者满足相同的约束（二次方程），且约束的对应项系数成比例。

验证步骤：

  1. 最高次项：直接目押二次项系数是否相等（或成比例）
  2. 常数项：赋值 t=0t = 0t=0，直接读出常数项
  3. 一次项：减去常数项再除以 ttt，继续赋值

:::note 注意 赋值时，尽量赋使约束中尽可能多项为零的值，避免展开。全过程没有展开复杂的 gig_igi​。

此技术由 R.W.（数之谜 @RynW1988）发明。 :::

例题​

彩蛋：USAMO 2024 P5​

题意（简述）：角条件使得三角形内部的钝角被两个底角平分，余角之和为 90°90°90°。

解题要点：

  • 角条件使得正切值一个是 ttt，一个是 1/t1/t1/t；
  • 要验证的是「相切」条件对 ttt 的约束与其他条件对 ttt 的约束等价；
  • 使用赋值不展开：验证两个二次约束对应项系数成比例，没有显式解出 ttt。

:::caution 难度提示 如果这题没有思路，说明解析对你来说目前还不能用来做赛题。这是个合格线。 :::

例题：CGMO 2023 P4​

题意：四边形 ABCDABCDABCD 内接于圆 ω\omegaω，对角线 AC,BDAC, BDAC,BD 互相垂直交于 EEE。FFF 在 ADADAD 上，延长 FEFEFE 交 ω\omegaω 于 PPP。在 PEPEPE 上取 QQQ 使 PQ⋅PF=PEPQ \cdot PF = PEPQ⋅PF=PE。过 QQQ 作 ADADAD 的垂线交 BCBCBC 于 RRR，求证：RQ=RPRQ = RPRQ=RP。

框架：相互垂直的弦，设 E=(0,0)E = (0,0)E=(0,0)，令 AC⋅BD=1AC \cdot BD = 1AC⋅BD=1（设守恒量）。

圆 ABCDABCDABCD 方程（常见框架，可一笔写出）：

x2+y2−(c−a)x−(b+d)y+1=0x^2 + y^2 - (c-a)x - (b+d)y + 1 = 0x2+y2−(c−a)x−(b+d)y+1=0

其中 A(−a,0),C(c,0),D(0,d),B(0,−b)A(-a,0), C(c,0), D(0,d), B(0,-b)A(−a,0),C(c,0),D(0,d),B(0,−b)，ac=bd=1ac = bd = 1ac=bd=1。

结论验证：等腰用对称点翻译，验证约束与圆上的约束等价，使用赋值不展开。
