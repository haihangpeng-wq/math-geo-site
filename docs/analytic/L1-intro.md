# 引言

计算几何（解析几何方法做竞赛题）是数学竞赛中一项核心方法论。它将几何直觉与代数运算结合，使得许多纯几何方法难以处理的命题变得可计算、可验证。

**计算量大，是因为没掌握正确的技巧。** 一旦你学会了正确的世界观，解析的计算量其实非常可控，甚至很多题比纯几更快。

---

## 解析法的核心定位

解析适合的是：**纯直线型**的题目、含有**悬浮**的垂直和平行关系、**双对称**图形，以及那些比较**"丑"**的图形，或者**类一试**（涉及具体数值）的问题。

今天这门课专门讲**解析几何**的世界观。
