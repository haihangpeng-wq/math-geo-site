§1.2 交点坐标

在有垂直格子（如坐标轴）的图上解析会好一点，是因为坐标可以直接读取。当一个点同时在两条线上，你总可以用一个坐标去表示另一个。直线交点的最常见设法是 (t,kt)(t, kt)(t,kt)。其他情况下，直线的交点坐标取决于直线方程的复杂度：

两条简单直线：直接解出​

如果两条直线都很简单，就直接解出显式表达式。

公式卡片 简单直线联立

BF:by−x=−b+f,CE:cy+x=−c+eBF: by - x = -b + f,\quad CE: cy + x = -c + eBF:by−x=−b+f,CE:cy+x=−c+e

BF∩CE=A=[be−cfb+c, −1+e+fb+c]BF \cap CE = A = \left[ \dfrac{be-cf}{b+c},\ -1 + \dfrac{e+f}{b+c} \right]BF∩CE=A=[b+cbe−cf​, −1+b+ce+f​]

如上复杂度是可以写显式表达式（不设坐标变量）的极限，也是唯一一种情形。 超过这个复杂度就应该溢出设变量【跳转】。

代表例题：21 高联二 P2。

一简一繁：溢出设变量​

用简单直线的结构设坐标，用复杂直线形成约束。

公式卡片 溢出设变量

N=L1∩L2,L1:y=−t(x−2),L2:Ax+By+C=0N = L_1 \cap L_2,\quad L_1: y = -t(x-2),\quad L_2: Ax+By+C=0N=L1​∩L2​,L1​:y=−t(x−2),L2​:Ax+By+C=0

N=(2−t−1n, n),n=(2A+C)tA−BtN = \left(2 - t^{-1}n,\ n\right),\quad n = \dfrac{(2A+C)t}{A-Bt}N=(2−t−1n, n),n=A−Bt(2A+C)t​

其中 A,B,CA, B, CA,B,C 都是复杂的超代数直觉系数，强行设出系数多项式A,B,CA, B, CA,B,C（层层设变量！）,再找机会慢慢化简。

注意，有简单直线就不要设出双坐标，即用 ddd 和 kdkdkd 的形式，不要设两个独立字母。例如，如果你设O(−d, h),h=k1dO(-d,\ h),\quad h = k_1 dO(−d, h),h=k1​d，你容易忘了它们之间的线性关系，导致后面遇到 2mhd−1−2mk12mhd^{-1} - 2mk_12mhd−1−2mk1​ 时，很容易注意不到它等于 000。

代表例题：22 CMO P1。
