# 小结

## 知识体系

| 对象 | 核心工具 |
|------|----------|
| 坐标系 | 原点（生成最多）、坐标轴（对称轴优先）、1 的使用、建系框架 |
| 点 | 全正变量、溢出设变量、根号厌恶、距离平方、一自由度设法 |
| 直线 | 直线的头、整式形式、点线关系（垂足/对称点）、三点共线行列式、过原点直线系、角平分线 |
| 圆 | 共轴圆系、点圆共轴圆系、圆斜式（4 种情形）、四点共圆行列式、斜 BC 外心公式、布洛卡框架 |
| 圆圆关系 | 根轴、公切线、$\lambda_P = \lambda_Q$ 验相切 |
| 关键思想 | 简洁是宗教、根号厌恶、如图择正负、人造分式不可取 |

## 结语

解析的威力，不在于它能算所有题，而在于它在**适合它的场景里，提供了一套系统、高效、可操作的框架**。配合程序和 AI 做验算，这套工具可以让你在竞赛场上稳稳地落地一大类题目。
