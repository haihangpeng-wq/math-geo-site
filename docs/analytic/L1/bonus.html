彩蛋：23 年北秋 P3 综合例题

题目​

四边形 ABCDABCDABCD 内接于圆心为 OOO 的圆 Ω\OmegaΩ，设 ABABAB 与 CDCDCD 交于 EEE，ADADAD 与 BCBCBC 交于 FFF，ACACAC 与 BDBDBD 交于 GGG。设 ACACAC、BDBDBD 的中垂线分别与 EFEFEF 的中垂线交于 HHH、III，△HIO\triangle HIO△HIO 的外接圆和 Ω\OmegaΩ 的公共弦分别与 ACACAC、BDBDBD 交于 JJJ、KKK。已知 EFEFEF 的中垂线与 Ω\OmegaΩ 相切，求证：△GJK\triangle GJK△GJK 的外接圆与 Ω\OmegaΩ 相切。

解题思路​

1. 布洛卡框架建系​

Ω\OmegaΩ 是单位圆，G(0,a)G(0, a)G(0,a)。EF:y=a−1EF: y = a^{-1}EF:y=a−1，ef=a−1(a−1−a)ef = a^{-1}(a^{-1}-a)ef=a−1(a−1−a)。设 AC/BD:y=kix+aAC/BD: y = k_i x + aAC/BD:y=ki​x+a。

2. 求圆 HIOHIOHIO​

含有原点和两个简单坐标的圆，用行列式展开，直接求出 d,ed, ed,e。

3. 求根轴​

圆 HIOHIOHIO 与 Ω\OmegaΩ 相减，得到公共弦所在直线。

4. 生成悬浮圆 GJKGJKGJK​

用三对称方法（§3.5.D），三条边两两乘积配参数得到 GJKGJKGJK 的圆方程。

5. 验相切​

验证圆 GJKGJKGJK 的圆心到根轴的距离等于 111。

这道题是 §3.7.8 完全四边形框架的完美代表作，综合运用了布洛卡建系、牛顿线约束、悬浮圆生成、根轴验相切等绝大多数工具。
