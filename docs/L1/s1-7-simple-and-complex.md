# §1.7 一条简单直线和一条复杂直线相交

用简单直线的结构设坐标，用复杂直线形成约束。

> **公式卡片**
> $N = L_1 \cap L_2,\quad L_1: y = -t(x-2),\quad L_2: Ax+By+C=0$
> $N = \left(2 - t^{-1}n,\ n\right),\quad n = \frac{(2A+C)t}{A-Bt}$

其中 $A, B, C$ 都是复杂的超代数直觉系数，**强行设出系数多项式**（层层设变量！）。
