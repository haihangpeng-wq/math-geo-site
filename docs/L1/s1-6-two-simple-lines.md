# §1.6 两条简单直线相交：直接解出

如果两条直线都很简单，就直接解出显式表达式。

> **公式卡片**
> $BF: -y - x = -b + f;\quad CE: cy + x = -c + e$
> $BF \cap CE = A = \left[\frac{be-cf}{b+c},\ -1 + \frac{e+f}{b+c}\right]$

**如上复杂度是可以写显式表达式（不设坐标变量）的极限，也是唯一一种情形。** 超过这个复杂度就应该溢出设变量。
