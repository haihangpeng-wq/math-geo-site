# §2.2 不使用分式版直线方程

直接写整式版，好习惯节约时间。

> **公式卡片**
> $$\text{两点式：} (x_2-x_1)y - (y_2-y_1)x = x_2 y_1 - x_1 y_2$$
> $$\text{垂直平分线：} 2(y_2-y_1)y + 2(x_2-x_1)x = y_2^2 - y_1^2 + x_2^2 - x_1^2$$
> $$\text{两直线垂直：} (y_2-y_1)(y_4-y_3) + (x_2-x_1)(x_4-x_3) = 0$$

**不要人造分式。** 如果你生成一个分式的唯一目的是一会儿通分，那干脆不要生成它。

无论是截距式、点斜式还是斜截式，**直线的头是写直线最好的方法**。
