# 引言

计算几何（解析几何方法做竞赛题）是数学竞赛中一项核心方法论。它将几何直觉与代数运算结合，使得许多纯几何方法难以处理的命题变得可计算、可验证。

**计算量大，是因为没掌握正确的技巧。** 一旦你学会了正确的世界观，解析的计算量其实非常可控，甚至很多题比纯几更快。

---

# 计算几何总纲

**适合计算的题目在正确的计算后会迎刃而解，一样有最高效的条件/结论转化效率。**

## 五大方法对比

| 方法 | 擅长场景 |
|------|----------|
| **复数** | 一个圆、旋转、角信息、相似 |
| **解析** | 纯直线型、悬浮垂直平行、双对称、丑图、类一试 |
| **三线坐标** | 一个重要三角形 + 多对象过顶点 |
| **向量（点乘、叉乘、线性运算）** | 字面意思，通向几何代数（Geometric Algebra / Clifford Algebra） |
| **三角 + 纯几（及算边方法）** | 以上方法的总兜底和补集 |

## 解析法的核心定位

解析适合的是：**纯直线型**的题目、含有**悬浮**的垂直和平行关系、**双对称**图形，以及那些比较**"丑"**的图形，或者**类一试**（涉及具体数值）的问题。

今天这门课专门讲**解析几何**的世界观。
