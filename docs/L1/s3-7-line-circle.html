§3.7 直线和圆的关系

3.7.0 情形零：相切（四种情况）​

已知情况处理方法
已知圆心、已知切点验切线与半径垂直
未知圆心、已知切点切点生成点圆，共轴圆系验 λP=λQ\lambda_P = \lambda_QλP​=λQ​
已知圆心、未知切点移轴到圆心，验原点到直线距离 = 半径
未知圆心、未知切点最后手段：联立判别式 Δ=0\Delta = 0Δ=0

要点： 能用几何方法验相切，就不要联立判别式。

3.7.1 情形一：圆斜式​

通法： 移轴至直线和圆的一个交点 A 并联立。

公式卡片 圆 ABC:x2+y2−dx−ey=0,AP:y=kx\text{圆 } ABC: x^2 + y^2 - dx - ey = 0,\quad AP: y = kx圆 ABC:x2+y2−dx−ey=0,AP:y=kx xP=d+ek1+k2,yP=k(d+ek)1+k2x_P = \frac{d+ek}{1+k^2},\quad y_P = \frac{k(d+ek)}{1+k^2}xP​=1+k2d+ek​,yP​=1+k2k(d+ek)​

这是对韦达的上位替代。

后续操作：

  • 坐标是二次分式，要设成 (p,kp)(p, kp)(p,kp)
  • (a) 验证 p=f(k)=g(k)p = f(k) = g(k)p=f(k)=g(k) 是恒等式
  • (b) 时刻留意 p(k2+1)=d+ekp(k^2+1) = d + ekp(k2+1)=d+ek 是整式，设而不求整体消去

代表例题：24 CMO P2、24 高联二 P2。

没有中点相关结论，不要使用韦达。

3.7.5 情形二：弦端点​

公式卡片 xP=kd+ek−1+k,yP=ke−dk−1+kx_P = \frac{kd+e}{k^{-1}+k},\quad y_P = \frac{ke-d}{k^{-1}+k}xP​=k−1+kkd+e​,yP​=k−1+kke−d​

3.7.6 情形三：截距式直线​

公式卡片 A2=1−en,A0=1−dm,−A1=dn+emA_2 = 1 - en,\quad A_0 = 1 - dm,\quad -A_1 = dn + emA2​=1−en,A0​=1−dm,−A1​=dn+em k1+k2=−A1A2,k1k2=A0A2k_1 + k_2 = -\frac{A_1}{A_2},\quad k_1 k_2 = \frac{A_0}{A_2}k1​+k2​=−A2​A1​​,k1​k2​=A2​A0​​

3.7.7 情形四：反解 PQ​

公式卡片 记 k1+k2=αk_1 + k_2 = \alphak1​+k2​=α，k1k2=βk_1 k_2 = \betak1​k2​=β，则 α=dn+em1−en,β=1−dm1−en\alpha = \frac{dn+em}{1-en},\quad \beta = \frac{1-dm}{1-en}α=1−endn+em​,β=1−en1−dm​ 反解出 m/nm/nm/n 即得 PQ。
