# §0.1 关于解析与复数的常见说法辨析

## "解析用两个字母，复数用一个字母"

这个说法只有一定程度上对。

确实，解析里一个点 $P(x, y)$ 有两个字母。但这两个字母包含了**坐标轴的信息**。

## 共轭不可缺

反过来看复数，一个点 $z$，如果你想知道它在不在单位圆内，就需要用到 $z$ 和它的共轭 $\bar{z}$。求实轴上的投影，也需要共轭。旋转，又要用共轭。

> **公式卡片**
> $$\text{判断 } z \text{ 在单位圆内/外？需要 } z\bar{z}$$
> $$\text{求 } z \text{ 在实轴上的投影？需要共轭}$$
> $$\text{旋转？需要共轭}$$

所以，复数其实也经常是"两个字母"的，大约 70% 的情况下，复数比解析节省大约一半的书写量。

## 解析的独特优势

很多时候，刻画两个点的位置关系，你只需要知道其中**一个坐标**。比如，你要证两个点的连线平行于某条已知线，你只需要让坐标轴和那条线平行，然后证两点的某一个坐标相等就行了。

**横纵坐标分离，不是净损失，有利有弊。**
