# §1.9 点和点的关系

## 距离公式

> **公式卡片**
> **永远计算距离的平方，而不是距离本身。**
> $PQ^2 = (x_P - x_Q)^2 + (y_P - y_Q)^2$

只要你的计算结果里出现了根号，你就是在自我欺骗——因为你一会儿还要两边平方。平方之后不损失任何信息。

## 同一直线上两线段乘积

> **公式卡片**
> $\overrightarrow{XB} \cdot \overrightarrow{XC} = (b-x)(c-x)(1+k^2)$

已知斜率为 $k$ 的直线，两个根号一乘就消掉了。这个形式非常常见。
