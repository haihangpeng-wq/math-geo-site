# §0.4 "1" 的使用

> **公式卡片**
> **必须使用！计算简洁迅速优先于保齐次。**

## 选取原则

不设最先遇到、最自然的量，而设**参与图形生成最多的量**。

## 五种常见场景

**A. 圆上点最多的圆设为单位圆**

如果有一个特别重要的圆上面有很多点，设它为半径 1 的单位圆。

**B. 乘积、平方、根号相关量统一设为 1**

图形里有**相交弦**，就设对应的圆的幂为 $1$；图形里有**守恒量**，就设那个守恒量为 $1$。

**C. $ab = cd = 1$**

对应切割线定理、相交弦定理、圆幂等场景。

**D. $ab \cdot cd = mn^2 = 1$**

更复杂的乘积守恒结构。

**E. $\sqrt{ab \cdot de} = bc = cd = 1$**

根号混合乘积结构。代表例题：**24 俄罗斯奥赛 P4**、**19 B 卷二试 P3**。
