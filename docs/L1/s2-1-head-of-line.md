# §2.1 不使用点斜式 / 圆的标准方程

用**直线的头**，**圆的头**展开直接写，好习惯减少错误。

## 直线的头

教材里，写一条斜率为 $k = A/B$ 的直线，会先写 $y = (A/B)x + C$，代入一组点求 $C$，再通分。

**正确的方法：**

> **公式卡片**
> $$k = \frac{A}{B},\quad \text{直线的头 } By - Ax = By_1 - Ax_1$$

带入一组已知点 $(x_1, y_1)$，常数项就是 $By_1 - Ax_1$。

类似地，圆有圆的头。
