# §0.3 坐标轴

## 对称轴优先


代表例题：**2409 迷赛 P1**。

原因：对称操作的公式在一般情况下**非常丑**。但如果你把对称轴放平——也就是让它成为坐标轴——公式就会极大简化。

## 均匀分配原则

> **尽量将计算简洁度均匀分配给各关键点。** 不要让一个点特别干净而其他点特别脏，要找一个平衡。

代表例题：**99 IMO P5**。

## 垂直条件优先级不高

很多人看见"垂足"就想把垂足所在的直线设成坐标轴。但其实，因为存在**点到直线的垂足公式**（不只是原点版），所以不必见到垂直就定轴。

**原点到直线垂足公式：**

> **公式卡片**
> $$\text{设直线 } Ax + By + C = 0 \text{，原点的垂足为}$$
> $$\left( \frac{-AC}{A^2+B^2},\ \frac{-BC}{A^2+B^2} \right)$$

你完全可以**先移轴，让那个点变成原点，用原点的垂足公式，再移回去。**

命题人大概率不知道这件事——否则很多三星题就变成两星题了。
